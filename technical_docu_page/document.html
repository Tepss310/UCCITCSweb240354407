Visual Studio Code (VS Code) is a free, open-source code editor developed by Microsoft. It is highly extensible, lightweight, and available on Windows, macOS, and Linux.

VS Code supports JavaScript, TypeScript, and Node.js out of the box, and offers extensions for hundreds of additional languages and tools.

Features
// Example: Creating a new VS Code window code --new-window myProject
  • IntelliSense for code completion and error detection
  • Integrated Git, GitHub, and version control features
  • Built-in debugger for multiple languages/frameworks
  • Integrated terminal with multi-shell support
  • Fully customizable layout and workspace settings

    • VS Code boosts productivity with refactoring tools, syntax highlighting, file search, and rich debugging capabilities.

    Its lightweight nature makes it suitable for everything from quick edits to large-scale development.

    Extensions
    // Install an extension from terminal code --install-extension ms-python.python
  • Python by Microsoft
  • Java Extension Pack
  • C/C++ Tools
  • Prettier – Code Formatter
  • Live Server for real-time web previews

    • Extensions enhance VS Code with language support, themes, debuggers, linters, and more.

    You can browse, install, and manage extensions directly from the Extensions Marketplace within VS Code.

    Shortcuts
    // Example: Format document Shift + Alt + F
  • Ctrl + P – Quick file navigation
  • Ctrl + Shift + P – Open Command Palette
  • Ctrl + ` – Toggle integrated terminal
  • Ctrl + B – Show/hide sidebar
  • Ctrl + / – Toggle line comment

    • Keyboard shortcuts significantly speed up workflow and reduce mouse usage.

    You can customize all keybindings through the Keyboard Shortcuts editor.

    Settings & Themes
    // Example: Open settings JSON Ctrl + Shift + P → "Open Settings (JSON)"
  • Light, Dark, and high-contrast themes
  • Customizable icon packs
  • Adjustable fonts, zoom, and editor layout
  • Workspace-specific settings
  • Keybinding customization

    • VS Code includes an extensive settings system accessible via UI or settings.json for advanced control.

    You can personalize themes, icons, layouts, and configurations to suit your workflow.
